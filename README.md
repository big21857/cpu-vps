## 先分清：叫"独享CPU"的其实是三种东西

行业内说独享，指的是下面三件不同的事，混着比价很容易买错。

**独享型云实例。** 底层还是虚拟机，但每个vCPU固定绑定到一个物理CPU超线程上。别人跑多满都抢不走你的时间片，性能稳定，价格比共享型贵，但远比物理机便宜。

**专用高主频CPU的VPS。** 严格说CPU仍然是虚拟化切出来的，卖点在于"这台机器的CPU不混用"加上主频够高。适合Minecraft服务端、编译、实时转码这一类吃单核的活儿。

**裸金属物理机（独服、BMS）。** 没有虚拟化层，整台机器归一个人用，CPU、内存、硬盘、网卡全是自己的。想自己装虚拟化平台、跑嵌套虚拟化、盯NUMA布局，只有这一档能满足。

判断依据不是预算高低，是负载形态。下面几个信号出现一个，就该认真考虑升级：

- 持续CPU使用率长期贴着80%以上。偶发飙高正常，长期贴顶说明资源确实不够。
- 延迟毛刺和业务无关。同一份代码上午跑得好好的，凌晨突然变慢，说明抢资源的是别人不是自己。
- 监控里CPU steal或就绪等待（CPU ready）偏高，运行队列长度一直在涨。
- p95、p99延迟比平均值难看得多。平均值好看没用，用户感受到的是长尾。

反过来说，个人博客、低频后台、开发测试环境这类负载，共享vCPU完全够用，多花的钱换不来体感差别。

> "独享"通常只针对CPU和内存。硬盘和带宽即使在这类实例上也可能处在共享的存储池和网络里，只是有QoS兜底。想要全硬件独享，直接看物理机那一档。

## 几个被问得最多的问题

**独享CPU等于独占整台物理机吗？**
不等于。独享型实例仍是虚拟机，只是CPU和内存固定分配给单一租户；独占整机是物理机/裸金属，成本更高。

**流量跑完了会断网吗？**
不会。流量叠加型套餐用完高速流量后会被限速（宁波、十堰、襄阳一带限速档位是5Mbps，日本部分区域限速1Mbps），可以加购流量包，宁波物理机额外流量是35元/1TB。用不完的流量次月不清零，会自动叠加。

**硬盘和IP怎么收费？**
硬盘可弹性扩容，高速固态约0.4元/GB/月（多数区域上限250GB），机械盘约0.1元/GB/月。独立IP单独计费：香港、日本、美国等海外区域普通IP常见5元/个/月，宁波物理机普通IP 30元/个/月，高防IP或特殊线路会更贵。

**国内机房都要备案吗？**
大陆机房的域名HTTP业务需要先完成备案并过白，才能用域名访问；香港、日本、美国等海外区域免备案。

**物理机能自己进BIOS吗？**
雨云用 NanoKVM 做远程管理，测评里提到可以尝试进入BIOS，但厂商给BIOS设了密码，日常够用的参数调整还是有的。
